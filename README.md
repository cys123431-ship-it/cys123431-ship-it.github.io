# 문서 다운로드 정적 페이지

이 저장소는 문서를 올려두고 다른 컴퓨터에서 다운로드할 수 있게 만든 정적 페이지입니다.

## 접속 주소

```txt
https://cys123431-ship-it.github.io/
```

## 파일 추가 방법

1. `files` 폴더에 문서 파일을 넣습니다.
   - 예: `files/toeic.docx`
   - 예: `files/report.pdf`

2. `files.json`에 문서 정보를 추가합니다.

```json
{
  "title": "토익 자료",
  "name": "toeic.docx",
  "type": "docx",
  "description": "토익 공부용 문서",
  "date": "2026-07-02"
}
```

`name` 값은 실제 파일명과 정확히 같아야 합니다.

## 주의

정적 페이지는 로그인/비밀번호 기능이 없습니다. 공개되면 주소를 아는 사람이 파일을 받을 수 있습니다.
민감한 문서는 올리지 마세요.
